# TAVRN capacity-40 1200-second benchmark backup

This directory preserves the 2026-08-16 six-board `FULL_TAVRN` / `BALANCED`
benchmark of radio-stack commit `18c94cb0e49a1da88317d73f6ae2b4691c8df10c`.
The hardware capture ran for the full 1200 seconds, but the canonical summarizer
classified it `INVALID_TELEMETRY_INCOMPLETE_EVIDENCE`: role A's observer queue
reached 1024 entries and reported 3985 dropped telemetry events. These files are
failure evidence and provisional measurements, not an accepted benchmark.

- [`metrics-provisional.md`](metrics-provisional.md) tabulates the requested PDR,
  application goodput, and latency values.
- [`benchmark-1200-exec.tar.zst`](benchmark-1200-exec.tar.zst) is the complete
  98 MiB run bundle compressed to approximately 24 MiB. It contains immutable
  inputs, six raw UART logs, the SQLite observation store, generated outputs,
  and `run.json`.
- The top-level CSV and Markdown files are convenience copies generated by
  `microbit/scripts/summarize_tavrn_benchmark.py`.
- [`charts/`](charts/) contains the six PNGs generated from `final.json` by the
  same summarizer with pinned `matplotlib==3.11.1`. Red shading marks invalid
  telemetry intervals.
- [`SHA256SUMS`](SHA256SUMS) binds every preserved artifact and chart.

Extract the full bundle with:

```sh
tar --zstd -xf benchmark-1200-exec.tar.zst
```
