# TAVRN observer-v3 1200-second benchmark evidence

This directory preserves the 2026-08-20 six-board `FULL_TAVRN` / `BALANCED`
benchmark produced from commit
`beb776a029a3843117ded3a4523841a6208451ac` and tree
`ca05db20346e520742b09fc544fca1e92c803e6e`.

The UART captures completed their approximately 1200-second windows, but the
command harness timed out after capture and before the runner wrote `run.json`
or finalized analysis. No capture process remained afterward. Recovery used the
pinned analyzer, immutable inputs, six raw UART logs, and intact SQLite store.
`run.recovered.json` records this as `recovered_after_runner_timeout` and uses
the latest observed serial timestamp as a conservative terminal boundary.

Role C ended with one 184-byte partial UART record. The analyzer right-censored
that terminal fragment rather than parsing it. The resulting evidence contains
18,234 complete records, zero invalid telemetry intervals, and no UART, FIFO,
mesh, or router faults.

## Result status

- Overall proving status: `VALID`.
- Application, transport, and control domains: `VALID`.
- GTT domain: `INCOMPLETE` because role E had one 12,034 ms snapshot interval,
  34 ms beyond the strict cadence limit. Reporting resumed, and the final nine
  fleet windows contained all six boards with precision, recall, Jaccard, and
  pairwise agreement equal to 1.0.
- [`metrics.md`](metrics.md) contains exact application, burst, control-proxy,
  and GTT aggregates generated from the finalized observer-v3 bundle.

## Preserved artifacts

- `run-1200.tar.zst`: complete 104 MiB run directory compressed to about 24 MiB;
  includes pinned inputs and tools, six UART logs, SQLite observations, recovery
  metadata, finalized JSON/CSVs/Markdown, and charts.
- `run.recovered.json`: recovery metadata and hashes for the original evidence.
- `recovery-analysis.log`: output from the pinned offline analyzer invocation.
- `final/final.json`: directly usable finalized bundle for
  `microbit/scripts/compare_tavrn_benchmarks.py`.
- `final/*.csv`, `final/final.md`, and `final/*.png`: normalized convenience
  reports and charts. The archive retains the original generated bytes.
- `SHA256SUMS`: hashes every preserved artifact except itself.

Verify and inspect the archive with:

```sh
sha256sum -c SHA256SUMS
tar --zstd -tf run-1200.tar.zst >/dev/null
```

After a new AODV run is finalized, compare it directly with:

```sh
python microbit/scripts/compare_tavrn_benchmarks.py \
  --left /path/to/aodv/final.json \
  --right microbit/hardware-results/2026-08-20-tavrn-observer-v3-benchmark-1200-recovered/final/final.json \
  --left-name AODV \
  --right-name FULL_TAVRN \
  --output /path/to/comparison
```
